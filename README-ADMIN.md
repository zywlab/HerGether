# 她聚申诉管理后台使用指南

## 🚀 快速启动

### 方案一：独立Web管理后台 (推荐)

1. **直接访问管理页面**
   ```
   打开浏览器访问：http://your-domain.com/admin.html
   ```

2. **本地开发测试**
   ```bash
   # 在web目录下启动简单HTTP服务器
   cd apps/web
   python3 -m http.server 8080
   # 或使用Node.js
   npx serve .
   
   # 然后访问：http://localhost:8080/admin.html
   ```

### 方案二：集成到现有Web应用

1. **启动Web应用**
   ```bash
   cd apps/web
   npm install
   npm start
   ```

2. **访问管理后台**
   ```
   http://localhost:3000/admin/appeals
   ```

## 📱 申诉处理流程

### 小程序端（用户）
1. 用户在小程序个人资料页看到"申请人工审核"按钮
2. 点击进入申诉页面，上传身份证照片
3. 填写申诉原因（默认：AI人脸性别识别错误）
4. 提交申诉，获得工单号

### Web后台（管理员）
1. 工作人员打开管理后台
2. 查看待处理申诉列表
3. 点击"查看详情"查看AI照片和身份证照片
4. 一键操作：
   - **批准申诉**：自动将用户性别修改为AI识别的相反性别
   - **拒绝申诉**：保持用户现有验证状态不变

## 🛠️ 部署配置

```bash

# 管理员JWT密钥
```

### API端点
```
POST /api/appeal/create-ticket        # 创建申诉工单
GET  /api/admin/appeals              # 获取申诉列表  
POST /api/admin/appeals/quick-process # 快速处理申诉
GET  /api/users/:id/appeal-status    # 获取申诉状态
```
